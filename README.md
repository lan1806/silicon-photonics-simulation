# Silicon Photonics Simulation

This repository contains simulation and optimization projects for silicon photonic devices using Lumerical FDTD and Python.

## Project 1: Silicon Ring Resonator

### Objective
Build and optimize a silicon ring resonator and investigate the influence of key geometric parameters on its transmission spectrum and resonance characteristics.

### Tools
- Ansys Lumerical FDTD
- Python
- MATLAB

### Main Tasks
- Device structure modeling
- Parameter sweep and optimization
- Transmission spectrum analysis
- Resonance wavelength extraction
- Q-factor analysis
- Python-based data processing and visualization

### Repository Structure
- `simulation/` : Lumerical simulation files and scripts
- `python/` : Python post-processing scripts
- `data/` : Simulation output data
- `figures/` : Processed figures and visualization results
